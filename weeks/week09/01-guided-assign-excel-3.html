New ideas this week

This module is about working with a bigger sheet: keeping it readable, pasting only part of what you copy, and seeing trends at a glance. The instruction file uses these words without explaining them, so here they are in one place.

The Excel ideas this assignment uses, with the moment in the video where each one comes up.
IdeaWhat it meansIn the video
Freeze PanesKeeps chosen rows or columns on screen while you scroll, usually the headings. Unfreeze Panes turns it off.
Middle Align vs. CenterMiddle is vertical: halfway between the top and bottom of the cell. Center is horizontal: halfway between left and right.
NOWA function with nothing inside the parentheses, =NOW(). It shows the current date and time, and updates whenever the workbook recalculates.
Insert FunctionThe fx button beside the Formula Bar. Search for a function by name or description and Excel builds it for you.
Format PainterCopies only the formatting of what you've selected, and applies it to the next cells you click.
Paste optionsThe arrow under Paste lets you paste only part of what you copied: Values (just the numbers), Formulas, or Formulas and Number Formatting, leaving the destination's other formatting alone.
Goal SeekA what-if tool. You name the result you want in one cell, and Excel works backward to find the value another cell would need.
SparklineA tiny chart inside a single cell that shows the trend of a row of numbers. Line and Column are the two types this week.
Fill Without FormattingCopies what's in a cell down a range but leaves each cell's existing formatting, like alternating row colors, alone.
Absolute referenceA cell reference with dollar signs, like $I$13, that stays the same when the formula is copied. In the video I call this "freezing" the row or column. That's a different thing from Freeze Panes.
Data labelsThe numbers printed on a chart, one per data point.

Why step 10 needs $I$13

Each month's share is that month's total (row 13) divided by the grand total in I13. When you copy =C13/I13 one column to the right, Excel shifts every reference one column: you'd get =D13/J13, and J13 isn't the grand total.

Dollar signs lock the part they sit in front of. =C13/$I$13 copies as =D13/$I$13, =E13/$I$13, and so on. Click inside the reference and press F4 to cycle through the four forms:

  • $I$13 — column and row both locked. This is the one step 10 wants.
  • I$13 — only the row locked.
  • $I13 — only the column locked.
  • I13 — nothing locked, back where you started.

Whenever every copy of a formula should point at the same cell, that cell needs an absolute reference.

Four details worth knowing

  • Read the long steps one sentence at a time. Steps 8 and 11 each have several parts (insert the sparkline, fill it, then style it). Do each sentence before reading the next, the way I do at 13:15.
  • "Without formatting" means the alternating row colors stay. A normal fill-handle drag copies the first cell's background down the whole range. Right-drag instead and choose Fill Without Formatting (14:47). If right-dragging is awkward, do a normal drag, then pick Fill Without Formatting from the Auto Fill Options button that appears.
  • Goal Seek's "Set cell" is C4. I put C5 in first and correct it at 12:32. If your result looks wrong, undo it with Ctrl+Z and run Goal Seek again.
  • Paste the chart title as text. If you copy the title from the instruction file and paste it with Ctrl+V, it brings Word's formatting along (25:37). Typing the title is just as good.

Windows and Mac differences

The steps are the same on both. This week uses more of the ribbon than before (View, Data, Insert, the Sparkline tab and Chart Design), and a couple of mouse and keyboard tricks that differ on a Mac. Pick your platform.

On Windows

  • Enable Editing. Downloaded files open in Protected View with a yellow bar across the top. Select Enable Editing before anything works.
  • Rename a sheet: double-click the sheet tab, or right-click it › Rename.
  • Unfreeze: View › Freeze Panes › Unfreeze Panes.
  • Rotate text: the Orientation button in the Home tab's Alignment group, or the small launcher arrow in the Font or Alignment group › Alignment tab, and type 90.
  • Paste options: the arrow under Home › Paste, or right-click › Paste Special.
  • Goal Seek: Data › What-If Analysis › Goal Seek.
  • Sparklines: Insert › Sparklines. Select a sparkline and the Sparkline tab appears with Sparkline Color, Marker Color and the High Point / Low Point boxes.
  • Absolute reference: F4. On many laptops you need Fn+F4.
  • Chart: click the chart, then Chart Design › Change Chart Type and Add Chart Element › Data Labels.

On Mac

Cengage's material is written for Windows. Most of this assignment matches, but check these before you decide something is broken. I've done these assignments on a Mac myself. If a command genuinely isn't where I say it is, message me through the Canvas Inbox rather than guessing at a substitute.

  • No Protected View. There's no Enable Editing bar. The file opens ready to edit.
  • Right-click is Control-click, or a two-finger click on a trackpad. That's how you reach Rename, Column Width and Delete.
  • Unfreeze: the View tab. When panes are frozen, its Freeze Panes button reads Unfreeze Panes.
  • Fill Without Formatting: right-dragging is hard on a trackpad. Drag the fill handle normally, then click the Auto Fill Options button that appears and choose Fill Without Formatting.
  • Paste options: the arrow beside Home › Paste, or Edit › Paste Special in the menu bar.
  • Goal Seek: Data › What-If Analysis › Goal Seek, the same as Windows.
  • Absolute reference: ⌘+T cycles the dollar signs the way F4 does on Windows. Typing the dollar signs works too.
  • Chart: click the chart, then the Chart Design tab, as on Windows.
