New ideas this week

This module is the most "business" of the four. You don't need a finance background; you need to know what each function wants and where to find it. The instruction file uses these words without explaining them, so here they are in one place.

The Excel ideas this assignment uses, with the moment in the video where each one comes up.
IdeaWhat it meansIn the video
Protected sheetA sheet locked against changes, sometimes with a password. You have to unprotect it before you can edit.
Defined nameA name, like Employer_Match, given to a cell. You can use it in formulas instead of the cell reference. Names can't contain spaces, so they use underscores.
Name ManagerThe list of every defined name in the workbook, what cell each refers to, and its current value. Edit, add and delete names here.
Create from SelectionNames a set of cells all at once, using the labels next to them. "Left column" means the labels are to the left of the values.
FV, PMT, PVFinancial functions. FV: what regular payments grow to. PMT: the regular payment on a loan. PV: what a series of future payments is worth today.
Data tableA what-if tool that reruns a formula for a list of different inputs and shows every result. A one-variable table changes one input; a two-variable table changes two at once.
Input cellThe cell a data table swaps its values into. Column input when your inputs run down a column, row input when they run across a row.
Error CheckingFinds cells showing errors, says what kind, and offers to edit them. #NAME? means Excel doesn't recognize a word in the formula; #VALUE! means the formula is using the wrong kind of data, such as text in a subtraction.
Print areaThe part of a sheet that prints. Excel marks it with a thin dashed line.

The three rules for FV, PMT and PV

Steps 5, 13 and 14 all follow the same pattern. Get these three things right and the function dialog does the rest.

  • Rate is per month. The sheet gives an annual rate, but payments are monthly, so divide it by 12: Annual_Rate/12.
  • Periods are months. The sheet gives years, so multiply by 12: Years*12. If you subtract first, as in step 14, wrap the subtraction in parentheses.
  • Money you pay out is negative. That's why each step says "negative" for the payment or principal. Leave the minus off and you get the right number with the wrong sign (11:30).

Only the arguments shown in bold in the Function Arguments dialog are required. The others can stay empty (12:36).

The assignment, step by step

Four setup items, then the fifteen graded steps, then submitting. Each one says what to change; the time button next to it shows you how. Always go by the instruction file MindTap gave you. The wording below is a summary, and MindTap grades against its own file.

Four details worth knowing

  • Three worksheets. Steps 1 through 11 happen on Investments (step 11 hides Salary); steps 12 through 15 on Loans.
  • Re-apply each border in step 2. Picking a color doesn't change borders that are already there. In More Borders, pick the color first, then click each existing border line in the preview, the thick one and both thin ones (4:35).
  • Names use underscores, never spaces or dashes. Type Years_until_Balloon, not Years-until-Balloon. As you type, Excel offers the matching names; double-click one to insert it exactly (10:00).
  • Select the whole data table, formulas included. For step 6 that's B22:D28 and for step 8 it's F8:N19, including the formula row or corner cell at the top.

Windows and Mac differences

The steps are the same on both. Most of this week is on the Formulas and Data tabs, which look much the same on Mac and Windows. Pick your platform.

On Windows

  • Enable Editing. Downloaded files open in Protected View with a yellow bar across the top. Select Enable Editing before anything works. That's different from the sheet protection in step 1.
  • Unprotect: right-click the sheet tab › Unprotect Sheet, or Review › Unprotect Sheet.
  • Border color: the arrow beside the Borders button › More Borders.
  • Names: Formulas › Name Manager and Formulas › Create from Selection.
  • Functions: Formulas › Insert Function, or the fx button beside the Formula Bar.
  • Data tables: Data › What-If Analysis › Data Table.
  • Error Checking: Formulas › Error Checking.
  • Hide a sheet: right-click the tab › Hide. Right-click any tab › Unhide to bring it back.
  • Print area: Page Layout › Print Area › Set Print Area.

On Mac

Cengage's material is written for Windows. Most of this assignment matches, but check these before you decide something is broken. I've done these assignments on a Mac myself. If a command genuinely isn't where I say it is, message me through the Canvas Inbox rather than guessing at a substitute.

  • No Protected View. There's no Enable Editing bar. The sheet protection in step 1 still applies, though.
  • Right-click is Control-click, or a two-finger click on a trackpad. That's how you reach Unprotect Sheet, Hide and Unhide on a sheet tab. Review › Unprotect Sheet works too.
  • Border color: Format › Cells › Border in the menu bar opens the same dialog as More Borders.
  • Names: the Formulas tab has Define Name and Create from Selection. If you don't see a Name Manager button, Define Name lists the existing names and lets you edit them.
  • Data tables and Error Checking: Data › What-If Analysis › Data Table and Formulas › Error Checking, as on Windows.
  • Print area: Page Layout › Print Area › Set Print Area, or File › Print Area in the menu bar.

Since this was recorded

A few things in the video are worth a note. Where this page and the video disagree, this page is right.

  • My Downloads folder is messier than yours. At 0:41 I delete old practice copies, and at 1:49 I delete a "(1)" from my file name that Windows added because of them. Your file name won't have one.
  • Two typos, both fixed on camera. An extra O in Employer_Match at 7:43, and a dash instead of an underscore in Years_until_Balloon at 38:52.
  • "84,216 invested" at 16:00. The invested amount counts only what the employee puts in each month (D16, about $584), not the $1,028 monthly total that includes the employer match. That's why it's less than 1,028 × 144.
  • "Hide" at 29:58. I say "click on Hide" while showing the list of hidden sheets. That list comes from Unhide.
  • "A 12-year loan" at 36:03. The sample loan is 15 years, as I say at 35:08. The balloon comes due at year 5.
  • No amortization schedule. The module is called Financial Functions, Data Tables, and Amortization Schedules, but this guided assignment has no amortization schedule step. That part is in the module reading.
  • Values as spoken. The border gray in step 2 sounds like "Gray, Accent 1, Darker 25%," and the rate range for the data table in steps 7 and 8 sounds like "2% to 7%." Go by your instruction file and the headings on your sheet.
  • Several garbled spots. At 1:24, 9:15, 13:50, 25:43, 31:39, 35:23 and 37:50 the automatic captions invented words, repeated themselves or filled silence. The transcript leaves those out; no instructions are missing.
  • Module release. Modules post on the Friday before the week begins, so Week 10 opened Friday 10/30. You can start early.
