The assignment, step by step

Four setup items, then the thirteen graded steps, then submitting. Each one says what to change; the time button next to it shows you how. Always go by the instruction file MindTap gave you — the wording below is a summary, and MindTap grades against its own file.

Before you start

  1. A

    Download all three files

    Instruction file, start file (your name, ending in _1), and the support image ending in Bank.png. They land in your Downloads folder.

  2. B

    Open the instruction file and read it

    It opens in Word. View › Page Width makes it readable. Keep it open in a second window while you work.

  3. C

    Open the start file and save it as the _2 version

    Select Enable Editing, then File › Save As. Leave it in Downloads, click just after the 1 in the file name, backspace, type 2, and save. Everything you do from here goes in the _2 file — that's the one you submit.

  4. D

    Check that it's your file

    Scroll to the bottom of the page. It should say the file was created specifically for you, by name. If it doesn't, delete it and download it again — a file with someone else's name won't grade as yours.

The thirteen graded steps

  1. 1

    Change the document theme colors to Blue II

    Design › Colors › Blue II. Not Themes — Colors. Nothing on the page appears to change; what changes is the set of colors offered in every color menu from here on, which is how the later turquoise steps find their color.

  2. 2

    Format the headline paragraph — four things

    Select the whole headline paragraph, then:

    • Home › Font › Change Case › Capitalize Each Word (it's in the Font group, not Paragraph)
    • Font size 36 pt
    • Text Effects › Fill: Turquoise, Accent 1; Shadow — the first tile in that row
    • Center the paragraph

    Watch the selection. In the video the 36 pt lands on a single letter because only that letter was selected. If that happens, Ctrl+Z, reselect the whole paragraph, and redo it.

  3. 3

    Resize the banking picture to 3" wide and apply Soft Edge Oval

    Click the picture, then Picture Format › set Width to 3" (the height follows on its own). Then open the full Picture Styles gallery and choose Soft Edge Oval — not Metal Oval, not Bevel Oval. Hover to read the names.

  4. 4

    Underline "four-hour session"

    It's in the fourth paragraph below the picture. Underline just that phrase, so it matches the "two-hour session" already formatted that way.

  5. 5

    Italicize "ideal for new bankers"

    Select the phrase, then Home › Italic. Just the phrase — not the whole sentence.

  6. 6

    Bullet the four paragraphs above the signature line

    The signature line is the last paragraph of text in the document. The four paragraphs above it are the ones that begin with bold words. Select all four and click the Bullets button — the plain default dot, not one from Define New Bullet.

  7. 7

    Set the bulleted list to Callisto MT, 14 pt

    With all four bullets selected, click into the font name box and type Calisto — far faster than scrolling the list. Then set the size to 14.

  8. 8

    Color the bold text Turquoise, Accent 1, Darker 25%

    Only the bold words at the start of each bullet. Do not include the colons. If the colon changes color, the grader marks that step wrong.

    Do the first one from Font Color, then for the rest either click the Font Color button (it keeps the last color) or select the text and press Ctrl+Y, which repeats the last command.

  9. 9

    Shade the signature-line paragraph Turquoise, Accent 1, Lighter 60%

    Click anywhere inside that paragraph — you don't need to select it. Then use the Shading (paint bucket) button in the Paragraph group, not the Font group. Shading applies to the whole paragraph.

  10. 10

    Same paragraph: spacing before 18 pt, spacing after 6 pt

    Open the Paragraph Settings dialog (the small arrow at the corner of the Paragraph group). Set Before to 18 pt and After to 6 pt — the arrows step in sixes, and After starts at 8, so take it down to 6.

  11. 11

    Insert the bank logo and resize it to 0.8" high

    Click the blank line at the bottom of the page, then Insert › Pictures › This Device and pick the support file ending in Bank.png from Downloads. Then Picture Format › Height 0.8", which is what brings the flyer back onto one page.

  12. 12

    Add a 1½ pt dotted page border in Turquoise, Accent 1

    Design › Page Borders (far right of the ribbon). In the dialog choose Box, set Color to Turquoise, Accent 1, Width to 1½ pt, and Style to the dotted line (second in the list). Apply to Whole document.

    Check the width after you click OK. In the video it comes out at ½ pt the first time. Reopen the dialog and confirm it really says 1½.

  13. 13

    Run Spelling & Grammar and fix the spelling error

    Review › Spelling & Grammar. Accept the correction it offers for the misspelled word. Ignore your own name, and ignore the "this file was created specifically for" line at the bottom — leave that text alone.

Submitting

  1. E

    Save, close, and exit Word

    Do this before uploading. A file still open in Word can upload incomplete.

  2. F

    Upload the _2 file and select Submit

    Drag and drop it into MindTap. Sorting your Downloads folder by Date Modified in Details view puts the file you just saved at the top.

  3. G

    Open the Graded Summary Report

    It downloads to the same folder and lists every step with the points it earned. Read it even if you got 25 out of 25 — and if you didn't, it tells you exactly which step to fix before your next attempt.

Windows and Mac differences

The steps are the same on both, but a few buttons live in different places. Pick your platform.

On Windows

  • Enable Editing. Downloaded files open in Protected View with a yellow bar across the top. You must select Enable Editing before anything works.
  • Ribbon collapsed? Right-click the ribbon or use the arrow at its right end and choose Always Show Ribbon, so the tabs stay visible as you click around.
  • Repeat the last command: Ctrl+Y. Undo is Ctrl+Z.
  • Finding your file: File Explorer, View › Details, then click the Date modified heading to sort newest first.

On Mac

  • No Protected View. There's no Enable Editing bar — the file opens ready to edit. Everything else in the walkthrough still applies.
  • Ribbon: if it's hidden, use the v chevron at the right end of the tab row, or View › Ribbon, to keep it showing.
  • Repeat the last command: ⌘+Y. Undo is ⌘+Z.
  • Page Borders is on the Design tab, same as Windows. The dialog looks slightly different but has the same Style, Color, Width and Apply to controls.
  • Finding your file: Finder › Downloads, switch to List view, then click Date Modified to sort newest first.
  • Callisto MT ships with Office on Mac too. If it's genuinely missing, message me through the Canvas Inbox rather than substituting a different font.

Since this was recorded

A few things will look different on your screen than they do on mine. Where this page and the video disagree, this page is right.

  • My file list isn't yours. I had already done this assignment once when I recorded, so my Saved Files list and my Downloads folder have extra copies in them. Yours will be emptier the first time through — that's normal, not a sign you did something wrong. (Video 1:54 and 28:44.)
  • The support file name. I say it out loud at 4:19 and it's a mouthful. Don't try to match it character for character — it's the one file that starts with Support and ends in Bank.png, and it's the only image in the download.
  • Attempts. Ten is what this assignment allows. Other weeks may differ, so go by the number shown on your own MindTap page rather than by the video. (Video 0:54.)
  • Module release. Starting this week, modules post on the Thursday or Friday of the week before, not Monday morning — so you can start early if you want to.

Using AI on this assignment

The course AI policy is Limited, and this assignment is exactly the kind of place it matters. You can ask an AI tool to explain what a command does, to tell you where something lives on the Mac ribbon when the video shows Windows, to troubleshoot an error, or to quiz you afterward. You build the Word file yourself. Spell check and grammar check are ordinary Word features and are always allowed — step 13 is literally asking you to use one.

The practical reason: the Word project later this week and the 200-point Word Project in Week 6 assume you can do these operations from memory. Watching someone else's file get formatted is not the same as formatting one.
