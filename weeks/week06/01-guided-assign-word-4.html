The assignment, step by step

Four setup items, then the ten graded steps, then submitting. Each one says what to change; the time button next to it shows you how. Always go by the instruction file MindTap gave you. The wording below is a summary, and MindTap grades against its own file.

Three details worth knowing

  • Page numbers mean the whole thing. In step 8, select the word Page and the number together. The first time I did this assignment I colored only the number and lost the point (16:07).
  • DRAFT 1 is a built-in watermark. Pick it from the Watermark gallery. Don't type the words "Draft 1" anywhere.
  • Step 5 says "bullets," but the final figure shows the text colored too. In the video I select the whole second-level items so the bullets and the text both change, to match the final figure (7:42). Compare your result to the final figure at the end of your instruction file.

The video says most step numbers out loud. The numbers below follow the order of the instruction file. If your file groups or numbers something differently, go by your file.

Before you start

  1. A

    Download all three files

    The instruction file, a start file with your name in it ending in _1, and the check-mark support file ending in .png. They land in your Downloads folder.

  2. B

    Open the instruction file and read it

    Select Enable Editing, then View › Page Width to make it readable. Keep it open in a second window. The final figure is at the very end of the file. Look at it before you start, and again after step 5 and step 10.

  3. C

    Open the start file and save it as the _2 version

    Enable Editing, then File › Save As. Leave it in Downloads, change the 1 in the file name to a 2, and save. Everything you do from here goes in the _2 file. That's the one you submit. The _1 file stays clean in case you want to restart.

  4. D

    Check that it's your file

    Scroll to the footer. It should show that the file was created specifically for you, by name. If it doesn't, delete it and download it again.

The ten graded steps

  1. 1

    Expand the title's character spacing by 1.5 pt

    Select the SPK Translation Services title. In the Font dialog's Advanced tab, set Spacing to Expanded, By: 1.5 pt. The letters spread out.

  2. 2

    Delete the page break and the blank paragraphs at the bottom of page 1

    With Show/Hide ¶ on, delete the page break and any empty paragraph marks after the picture, until the Why Choose SPK Translation Services heading sits directly under the picture. No blank lines left in between.

  3. 3

    Small caps on one item, then a picture bullet on the list

    In the Language Translation Services section:

    • Format English to Korean in Small caps (Font dialog) so it matches the other items.
    • Select the whole list, then Bullets › Define New Bullet › Picture › From a File, and choose the check-mark PNG you downloaded.

  4. 4

    Fix the indent levels in Interpretation Services

    • Increase the indent of the five items from Conferences through Medical Appointments by one level.
    • Decrease the indent of Zoom Interpretation by one level, so it's level with Phone Interpretation and Consecutive Interpretation.

    One click on Increase Indent or Decrease Indent moves an item one level.

  5. 5

    Turquoise, Text 2 on the second-level items in Legal Translation Services

    Select the second-level items (the ones indented under a top-level item) in the Legal Translation Services section, then Font Color › Turquoise, Text 2. Selecting the whole items colors the bullets and the text together, which is what the final figure shows.

  6. 6

    Indent and sort the Accurate Technical Translations list

    • Indent the list one level (about half an inch) so it matches the level-one lists in the rest of the document.
    • Then Sort it: Sort by Paragraphs, Type Text, Ascending (A to Z).

  7. 7

    A 1., a., i. multilevel list in the Questions section

    Select the list from Text and phone down to the company's address, then Multilevel List and the 1., a., i. format. The sub-items pick up letters automatically. There's no i level in this list.

  8. 8

    Color the page numbers in the header Turquoise, Text 2

    Double-click in the header, select the word Page and the number, and set the font color to Turquoise, Text 2. Double-click in the body to get back out.

  9. 9

    Add the DRAFT 1 watermark

    Design › Watermark › DRAFT 1, the built-in one. It appears on every page. On a Mac there's no built-in DRAFT 1, so follow the Mac note in your instruction file. In the video that means a text watermark reading DRAFT, set to 50% and diagonal.

  10. 10

    Insert the Retrospect cover page

    Insert › Cover Page › Retrospect. Then fill in:

    • Document Title: SPK Translation
    • Document Subtitle: Services for Companies and Individuals

    Retrospect shows the subtitle in all caps however you type it. Leave the other placeholders alone, the way the final figure does.

Submitting

  1. E

    Save and close both files

    Save the _2 file, close it, and close the instruction file too. A file still open in Word can upload incomplete.

  2. F

    Upload the _2 file and select Submit

    Drag and drop it into MindTap. Sorting your Downloads folder by Date Modified puts the file you just saved at the top.

  3. G

    Open the Graded Summary Report, and fix anything it flags

    It lists every step with the points it earned, and tells you which ones you missed. Fix that step in your _2 file, save and close it, then reopen the guided assignment in MindTap to start a new attempt, and upload again.

Windows and Mac differences

The steps are the same on both, except the watermark. Most of this week's commands are on the Home tab, and those look nearly the same on Mac and Windows. The differences are mostly in dialogs, menus and keyboard shortcuts. Pick your platform.

On Windows

  • Enable Editing. Downloaded files open in Protected View with a yellow bar across the top. You must select Enable Editing before anything works.
  • Show/Hide ¶: the ¶ button in the Home tab's Paragraph group, or Ctrl+Shift+8.
  • Font dialog: the small arrow at the corner of the Home tab's Font group, or Ctrl+D. Character spacing is on the Advanced tab; Small caps is on the Font tab.
  • Picture bullet: the arrow beside the Bullets button › Define New Bullet › Picture › From a file.
  • Sort: the A→Z button in the Home tab's Paragraph group.
  • Watermark: Design › Watermark, on the right end of the ribbon.
  • Finding your file: File Explorer, View › Details, then click the Date modified heading to sort newest first.

On Mac

Cengage's material is written for Windows. Most of this assignment matches, but check these before you decide something is broken. I've done these assignments on a Mac myself. If a command genuinely isn't where I say it is, message me through the Canvas Inbox rather than guessing at a substitute.

  • No Protected View. There's no Enable Editing bar. The file opens ready to edit.
  • Show/Hide ¶: the ¶ button on the Home tab, or ⌘+8.
  • Font dialog: Format › Font in the menu bar, or ⌘+D. Character spacing is on the Advanced tab.
  • Picture bullet: the arrow beside the Bullets button › Define New Bullet. The Mac dialog is laid out differently. If you can't find the picture option, check your instruction file for a Mac note, then message me.
  • Watermark: Design › Watermark opens a dialog instead of a gallery. Choose Text, type DRAFT, and set the transparency and orientation your instruction file asks for (50% and diagonal in the video).
  • Right-click is Control-click, or a two-finger click on a trackpad.
  • Finding your file: Finder › Downloads, switch to List view, then click Date Modified to sort newest first.
