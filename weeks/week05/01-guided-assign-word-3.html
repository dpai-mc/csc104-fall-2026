The assignment, step by step

Four setup items, then the thirteen graded steps, then submitting. Each one says what to change; the time button next to it shows you how. Always go by the instruction file MindTap gave you. The wording below is a summary, and MindTap grades against its own file.

Two details worth knowing

  • Shape Effects, not Text Effects. The shadow in step 12 goes on the shape itself. Both menus have a Shadow gallery with an Offset: Center in it. I use Text Effects at 22:47, which is a mistake, and I correct it later in the video at 26:15.
  • The period in the alt text. Step 4's alt text ends with a period. Leave it off and the step is marked wrong. Copy and paste it from the instruction file.

The video only says some step numbers out loud. The numbers below follow the order of the instruction file as it's read in the video. If your file groups or numbers something differently, go by your file.

Before you start

  1. A

    Download both files

    An instruction file and a start file with your name in it, ending in _1. They land in your Downloads folder.

  2. B

    Open the instruction file and read it

    Select Enable Editing, then View › Page Width to make it readable. Keep it open in a second window. You'll copy text from it for the alt text, the SmartArt and the table. The final figure is at the very end of the file, so scroll down and look at it before you start. It's the quickest way to check any step.

  3. C

    Open the start file and save it as the _2 version

    Enable Editing, then File › Save As. Leave it in Downloads, change the 1 in the file name to a 2, and save. Everything you do from here goes in the _2 file. That's the one you submit. The _1 file stays clean in case you want to restart.

  4. D

    Check that it's your file

    Scroll to the footer. It should show that the file was created specifically for you, by name. If it doesn't, delete it and download it again.

The thirteen graded steps

  1. 1

    Flip the logo and move it to the top left

    On page 1 the logo's text reads backwards. Select the picture, then on Picture Format:

    • Rotate › Flip Horizontal
    • Position › Top Left with Square Text Wrapping

  2. 2

    A double-line bottom border on the address line

    Click in the address line paragraph and open Home › Borders › Borders and Shading. Plain Bottom Border only gives you a single line. Set:

    • Style: the double line
    • Color: Red, Accent 1
    • Width: 1½ pt

    Pick the double line first, then the width. Choosing a line style resets the width to ½ pt. Then click the bottom edge in the Preview so the new border replaces the old one.

  3. 3

    Format Painter: "Why Red Arrow" to "Keep up with innovations…"

    On page 2, select the Why Red Arrow text, click Home › Format Painter (the paintbrush), then select the Keep up with innovations and technology text just after the picture. It picks up the red formatting.

  4. 4

    Correct, resize and describe the transportation picture

    Three changes to the same picture:

    • Correction: Brightness +40%, Contrast −20%. The Picture Format › Corrections gallery has this exact preset. Hover over the thumbnails to read their names. The video does it instead with right-click › Format Picture and the sliders. Either route works.
    • Width 6.5", proportionally. Change the width in Picture Format › Size and let the height follow.
    • Alt text: Vehicles and technology., including the period.

  5. 5

    Clear the formatting from one paragraph

    The paragraph that starts "In addition to discounts" and ends "and vendor options." Select it, then either expand the Styles gallery and choose Clear Formatting, or use the Clear All Formatting button (an A with an eraser) in the Home tab's Font group. All the red goes away.

  6. 6

    Insert a Grid Matrix SmartArt and fill it in

    On page 3, click in the blank paragraph after "The Red Arrow TechPLUS program offers benefits in four areas." Then Insert › SmartArt › Matrix › Grid Matrix.

    Put the four words from your instruction file in the four boxes, in the positions it gives. In the video they're Variety (top left), Flexibility (top right) and Support (bottom left). The fourth isn't read out loud, so take it from your file.

  7. 7

    Resize the SmartArt, then change its colors and style

    First, select the whole diagram. Click its outer frame, not one of the boxes inside it. Then:

    • Height 3", proportionally. Open the size settings (the small arrow at the corner of the Format › Size group, or right-click the frame › More Layout Options › Size). Check Lock aspect ratio first, then change the height from 3.5 to 3.
    • SmartArt Design › Change Colors › Gradient Range - Accent 1, the third choice in the Accent 1 row.
    • SmartArt Design › SmartArt Styles › Moderate Effect. Hover over the thumbnails to read their names. It's not one of the 3-D ones.

  8. 8

    A right tab stop at 5" on "Grants 2028"

    Click in the Grants 2028 paragraph. The video uses the tab selector at the far left end of the ruler: click it until it shows the right tab (an L flipped backwards), then click the ruler at 5". Turn the ruler on with View › Ruler if you can't see it.

    For an exact position, use the Tabs dialog instead: Home › Paragraph settings › Tabs, type 5", choose Right, then Set and OK.

  9. 9

    Add a last row to the Grants table

    Click in the last cell of the table, in the Vertical Gardening row, and press Tab. That adds a new row. (Or right-click › Insert › Insert Rows Below.) Type Veterans Coffee in the first column and $15,000 in the second.

  10. 10

    Apply the List Table 3 - Accent 1 table style

    Click anywhere in the Grants table, then Table Design, expand the Table Styles gallery, and find List Table 3 - Accent 1 in the List Tables section. You should see red, bold text in the first column. It should look like the table right below it.

  11. 11

    Wrap and recolor the Getting Started picture

    On page 4, the picture in the Getting Started section:

    • Picture Format › Wrap Text › Square, so the text flows around it instead of the picture sitting in front of it.
    • Picture Format › Color › Recolor › Red, Accent color 1 Light. The black picture turns red to match the Red Arrow brand.

  12. 12

    Style the Purchase Product shape and give it a shadow

    Select the Purchase Product shape by clicking its edge, so the whole shape is selected and not just the text inside it. Then:

    • Shape Format › Shape Styles › Moderate Effect - Black, Dark 1
    • Shape Format › Shape Effects › Shadow › Offset: Center, in the Outer group

    Shape Effects, not Text Effects. Text Effects has a Shadow gallery with the same Offset: Center in it, but that shadow goes on the letters. In the video I use Text Effects here by mistake, and I correct it later at 26:15.

  13. 13

    Format Painter: Select Vendor shape to Product ID shape

    Select the Select Vendor shape, click Format Painter, then click the Product ID shape. It's the same tool as step 3, used on shapes this time.

    Then compare the whole document against the final figure at the end of the instruction file.

Submitting

  1. E

    Save and close both files

    Save the _2 file, close it, and close the instruction file too. A file still open in Word can upload incomplete.

  2. F

    Upload the _2 file and select Submit

    Drag and drop it into MindTap. Sorting your Downloads folder by Date Modified puts the file you just saved at the top.

  3. G

    Open the Graded Summary Report, and fix anything it flags

    It lists every step with the points it earned. If one comes back short, the report says what it expected. In the video it says the shape should use the Shadow Offset: Center shape effect. Fix that step in your _2 file, save and close it, then reopen the guided assignment in MindTap to start a new attempt, and upload again.

Windows and Mac differences

The steps are the same on both. Most of this week's commands are on the object tabs (Picture Format, Shape Format, SmartArt Design, Table Design), and those look nearly the same on Mac and Windows. The differences are mostly in right-click menus, dialogs and keyboard shortcuts. The instruction file has a few Mac hints of its own (video 2:59). Pick your platform.

On Windows

  • Enable Editing. Downloaded files open in Protected View with a yellow bar across the top. You must select Enable Editing before anything works.
  • Copying between the two documents: Ctrl+C, then Alt+Tab to switch windows, then Ctrl+V. That's how the video fills in the SmartArt boxes.
  • Format Picture pane: right-click the picture › Format Picture › the Picture icon › Picture Corrections.
  • Alt text: Picture Format › Alt Text, or right-click › View Alt Text. If Word has already put in a generated description, replace it completely.
  • Lock aspect ratio: right-click the SmartArt frame › More Layout Options › Size tab.
  • Tabs dialog: the small arrow at the corner of the Home tab's Paragraph group › Tabs… button at the bottom left.
  • Finding your file: File Explorer, View › Details, then click the Date modified heading to sort newest first.

On Mac

Cengage's material is written for Windows. Most of this assignment matches, but check these before you decide something is broken. I've done these assignments on a Mac myself. If a command genuinely isn't where I say it is, message me through the Canvas Inbox rather than guessing at a substitute.

  • No Protected View. There's no Enable Editing bar. The file opens ready to edit.
  • Copying between the two documents: ⌘+C and ⌘+V. To switch between two Word windows use ⌘+` (the key above Tab). ⌘+Tab switches apps, not documents.
  • Right-click is Control-click, or a two-finger click on a trackpad.
  • Borders and Shading: the Borders drop-down on the Home tab › Borders and Shading…, or Format › Borders and Shading in the menu bar.
  • Picture corrections: the Picture Format › Corrections gallery is there too. For the sliders, Control-click the picture › Format Picture.
  • Alt text: Control-click the picture › Edit Alt Text…, or Picture Format › Alt Text.
  • Lock aspect ratio: in the size and position settings for the SmartArt frame (Control-click the frame, or the size options on the Format tab). If you can't find the check box, message me before you resize by hand.
  • Tabs dialog: Format › Tabs… in the menu bar. The ruler's tab selector works the same way as on Windows.
  • Finding your file: Finder › Downloads, switch to List view, then click Date Modified to sort newest first.
