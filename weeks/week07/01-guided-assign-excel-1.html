New words for Excel

Word and Excel share a lot (the ribbon, Save As, the file names, MindTap's grading), but Excel has its own vocabulary. The instruction file uses these words without explaining them, so here they are in one place.

The Excel words this assignment uses, with the moment in the video where each one comes up.
WordWhat it meansIn the video
WorkbookAn Excel file. This week's workbook has two worksheets in it.
Worksheet (sheet)One page of the workbook, chosen with the tabs along the bottom: Documentation and Current Accounts.
Cell, cell referenceOne box in the grid, named by its column letter and row number. B6 is column B, row 6.
Name BoxThe box at the upper left, above column A. It shows which cell you're in.
RangeA block of cells, written first cell to last: A3:J3 is the instructions' "A3 to J3".
AutoFitSizes a column to fit what's in it right now. It doesn't resize again later when you type more.
Number formatHow Excel treats and displays a value. Text tells Excel to treat it as text, not a number to calculate with.
AutoCompleteExcel offering to finish an entry that matches one already in the column. Press Enter to accept it. (In the video I call this "auto fill.")
FormulaA calculation in a cell. It always starts with =, and the cell shows the result.
Formula BarThe long box above the column letters. It shows the formula behind the result in the selected cell.
Fill handleThe small square at the bottom-right corner of the selected cell. Drag it to copy a formula into the cells next to it.
FunctionA built-in formula with a name, such as SUM. A formula "without a function" is plain arithmetic like =G4+7.

The assignment, step by step

Four setup items, then the twelve graded steps, then submitting. Each one says what to change; the time button next to it shows you how. Always go by the instruction file MindTap gave you. The wording below is a summary, and MindTap grades against its own file.

Three details worth knowing

  • Watch which worksheet you're on. Your name goes on the Documentation sheet. Every graded step happens on the Current Accounts sheet. Check the tabs at the bottom before you start step 1.
  • Formulas copy as formulas. When you fill =G4+7 down from H4, each row adds 7 to its own row's date: H5 uses G5, H6 uses G6, and so on. Select a cell and look at the Formula Bar to see it (11:45).
  • Step 2 says Clear Contents, so use Clear Contents. There are other ways to empty a cell, but the instructions name this one (5:49).

The video says some step numbers out loud. The numbers below follow the order of the instruction file. If your file groups or numbers something differently, go by your file.

Before you start

  3. C

The twelve graded steps

All twelve happen on the Current Accounts worksheet.

  1. 1

    Move the worksheet title from C2 to A2

    Cut the title Current Accounts from cell C2 and paste it into cell A2. It spills over column B, which is fine because B2 is empty.

  2. 2

    Copy Emmy Larson's name from G2 to C11, then clear G2

    Copy Emmy Larson's name in G2 and paste it into C11. Then use Clear Contents on G2, so the name is only in C11.

  3. 3

    Type Goal in C3

    Enter Goal as the column heading in the empty cell C3.

  4. 4

    Make the headings in A3:J3 12 point and bold

    Select the range A3 through J3 and set the font size to 12 and apply Bold. Some headings won't fit their columns afterward. Step 5 takes care of that.

  5. 5

    AutoFit columns G and H

    Resize columns G and H to their best fit with AutoFit Column Width. Either way in the video works: the Format menu with both columns selected, or a double-click on each column's right border.

  6. 6

    Apply the Text number format to D4:D9

    The phone numbers. Select D4 through D9 and change the number format from Number to Text. Nothing changes on screen. That's expected.

  7. 7

    Enter Social Media in E5

    In the empty cell E5, start typing. Excel offers Social Media from elsewhere in the column; press Enter to accept the complete entry.

  8. 8

    In H4, a formula that adds 7 days to G4

    Anywhere Fitness contacts each client once a week, so the follow-up date is seven days after the last contact. In H4, enter a formula without a function that adds 7 to G4.

  9. 9

    Fill H5:H9 with the formula from H4

    Drag the fill handle on H4 down to H9. Each row should show a date a week after its own last-contact date.

  10. 10

    Enter 2500 in J9

    The plan amount for Robert Bennett, the last client row. Type 2500 and press Enter. Excel picks up the number formatting from the cells above.

  11. 11

    SUM the plan amounts in J10

    In J10, enter a formula that uses the SUM function to add J4 through J9. AutoSum builds it for you; check that it picked J4 to J9 before pressing Enter.

  12. 12

    Landscape, and scale the sheet to fit on one page

    • Change the worksheet's Orientation to Landscape.
    • Change the print scaling so the sheet fits on one page: in the Scale to Fit group, set Width and Height to 1 page instead of Automatic.

    File › Print shows a preview if you want to check it.

Windows and Mac differences

The steps are the same on both. Most of this week's commands are on the Home and Page Layout tabs, and those look nearly the same on Mac and Windows. The differences are mostly in menus, right-clicking and keyboard shortcuts. Pick your platform.

On Windows

  • Enable Editing. Downloaded files open in Protected View with a yellow bar across the top. You must select Enable Editing before anything works.
  • Cut, Copy, Paste: the buttons at the left end of the Home tab, or Ctrl+X, Ctrl+C, Ctrl+V.
  • Clear Contents: right-click the cell › Clear Contents.
  • AutoFit: Home › Format › AutoFit Column Width (in the Cells group), or double-click the column's right border.
  • Number format: the drop-down box in the Home tab's Number group.
  • AutoSum: the Σ button at the right end of the Home tab, or Alt+=.
  • Orientation and Scale to Fit: both on the Page Layout tab.
  • Print preview: File › Print, or Ctrl+P.
  • Finding your file: File Explorer, View › Details, then click the Date modified heading to sort newest first.

On Mac

Read Introduction to Excel for Mac in this week's module first. Cengage's material is written for Windows. Most of this assignment matches, but check these before you decide something is broken. I've done these assignments on a Mac myself. If a command genuinely isn't where I say it is, message me through the Canvas Inbox rather than guessing at a substitute.

  • No Protected View. There's no Enable Editing bar. The file opens ready to edit.
  • Cut, Copy, Paste: the Home tab buttons, or ⌘+X, ⌘+C, ⌘+V.
  • Right-click is Control-click, or a two-finger click on a trackpad. That's how you reach Clear Contents. It's also under Edit › Clear in the menu bar.
  • AutoFit: double-clicking the column's right border works the same. The menu route is Format › Column › AutoFit Selection in the menu bar.
  • Number format and AutoSum: both on the Home tab, as on Windows.
  • Scale to Fit: on the Page Layout tab. If you don't see Width and Height boxes there, use Page Setup and set Fit to 1 page wide by 1 tall.
  • Print preview: File › Print, or ⌘+P.
  • Finding your file: Finder › Downloads, switch to List view, then click Date Modified to sort newest first.
